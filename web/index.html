fs_main runs once per pixel and returns its color (RGBA, 0..1).

u.resolution    canvas size, in pixels
u.time          seconds since start
u.bass          average loudness below 250 Hz, 0..1
u.mid           average loudness from 250 Hz to 4 kHz, 0..1
u.treble        average loudness above 4 kHz, 0..1
u.beat          1.0 on a beat, then fading out
u.params        4 free values, 0..1, set in the Tuning panel (.x .y .z .w)
band(i)         loudness of band i, 0..1 (i from 0 to 63, low to high)
band_at(t)      band loudness at t in 0..1, interpolated
hue(h)          RGB color from a hue in 0..1
note(n)         MIDI note n (60 = middle C): velocity 0..1, fading after release
                (the computer keyboard plays notes too, when not typing here)
cc(n)           MIDI controller n (knob, fader): 0..1

GLSL works too, written like on Shadertoy: define
void mainImage(out vec4 fragColor, in vec2 fragCoord) (fragCoord in pixels,
from the bottom left). iTime and iResolution work, and all the inputs above
(u.bass, band(i), note(n)... with int arguments). See the "glsl" visual.

Suggestions appear as you type (↑ ↓ to pick, Enter to accept, Esc to close).
Hover a name to see what it does. Ctrl+F searches, Ctrl+/ comments lines.
Once the language server runs (the LSP badge lights up): F12 goes to a
definition, Shift+F12 finds references, F2 renames, and calls show their
signature as you type.

Edits recompile when you stop typing and are saved in this browser.
With Auto compile off, they're still checked for errors and saved, but
only run on Compile (Ctrl+Enter); the Auto switch turns it on and off. Loops stop after 100000 iterations per
pixel, counting all loops, so an endless loop ends. If a shader still hangs
the GPU (too much work per pixel), the GPU is reset: the visual then runs a safe version until
you fix it and press Compile, and Auto compile is turned off.
Ctrl+S downloads the code as a file, like Export.
